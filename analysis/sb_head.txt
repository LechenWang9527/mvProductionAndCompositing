# 《The OGs》· 87 镜分镜表（305.9 s）

## 全片节奏曲线

- **总长 305.9 s / 87 刀 / 均 3.5 s**。三档密度：密 ≤2.8 s、中 2.8–4.6 s、疏 ≥4.6 s；全片只做「密—疏」交替，不许两个疏段连排。
- **0:00–0:30｜疏 6.0 s / 5 刀**：两刀开机（7.4 s、7.6 s）之后才进人声。系统先出声，人再出声。
- **0:30–1:14｜疏 5.0 / 4.8｜9 刀**：杜甫 + 杜甫之子。前段末镜 8.1 s（结算单），后段末镜 6.9 s 不动，是两个「熬」的体感。
- **1:14–1:30｜中 3.2 / 5 刀**：hook 回来。内部最后两刀压到 1.6 s，这是全片所有 hook 的固定收尾节奏型。
- **1:30–1:44｜疏 4.6 / 3 刀**：刘邦。整段只有 3 刀，靠静止和 10 只酒爵压出压力，是全片最「不动」的一段。
- **1:44–2:08｜密 2.5–2.7 / 9 刀**：手机、战争、账本三连。全片第一个密段，每段都短，不留喘息。
- **2:08–2:17｜中 3.1 / 3 刀**：风。末镜 1000 张档案卡是信息量最大的一刀，紧接着换色。
- **2:17–2:32｜中 3.0 / 5 刀**：马牌黄在 2:16.9 进场，此后不再退出；hook 版式不变，只换底色。
- **2:32–3:02｜中 3.7 / 8 刀**：必武 + PPT。信息最杂，靠 2.8–3.6 s 的中刀维持呼吸；只有 Give me five 一刀放到 5.2 s。
- **3:02–3:19｜疏 5.8 / 3 刀**：no-complaint。三段 5–7 s 长镜，用时长本身演「执着的坚持」；段尾 7 s 已在闪动安全区内。
- **3:19–3:34｜中 3.0 / 5 刀**：hook 第四次。此后不再有换色，只有换人。
- **3:34–4:05｜密 2.5 / 12 刀**：老曹、吴晗、高小凡、Gary 四连（各 3 刀）。姓名条像点名，全片最快的一段。
- **4:05–4:27｜中 3.0 / 7 刀**：传勇 + Allen。信息密度回落，给最后的密点让位。
- **4:27–4:33｜密 2.2 / 3 刀**：小马。全片最短刀距 1.4 s。
- **4:33–4:48｜中 3.1 / 5 刀**：hook 最后一次。版式与片头同构，只有底色和时态变了。
- **4:48–5:06｜中 3.6 / 5 刀**：finale。末镜 5.5 s 不动，只留一盏灯。
- **留白规则**：密段只出现在同一信息源内部（手机 / 战争 / 账本算一段，四人点名算一段）；跨段必留一刀 ≥3.4 s 作缓冲。hook 段内固定以 1.5–2.0 s 两短刀收尾，hook 之间不继承长度。
- **切点规则**：段落切点 = 下一段首行 start；段内切点 = 行首；全片只有 0:07.4 一处用拍边界（8 拍 = 7.43 s）；表中时间按 0.1 s 舍入，精确值取 og_timing.json。
- **全局规则·色与字**：四色即状态——system 冷黑暖白、ancient 宣纸墨朱砂、terminal 磷光绿琥珀、marpol 炭黑马牌黄。字体三分工——mono 系统与编号、serif 歌词、sans 界面与现代人名。
- **全局规则·人**：12 位同事只用姓名条 / 工牌 / 编号 / 剪影，全片零人脸、零真人照片、零外部图片，所有画面 Canvas2D 程序化绘制。
- **全局规则·闪动**：148.04–192.34 s 禁用高频闪白；该区间 12 刀全部硬切或遮罩，单镜亮度变化 ≤1 次。
