> 这份是给**你**照着做的。不用懂参数：上传 → 粘贴 → 收图 → 丢进目录 → 跟我说一声。

## 5. 图不对劲时，照着说

| 症状 | 回它这句话 |
|---|---|
| 太现代、像照片 | 「重画。用 R1 的木刻线条，不要照片质感，要刻出来的」 |
| 有彩色 | 「重画。只要墨色和旧纸色，不要任何彩色」 |
| 图里有文字 | 「重画。图里不要出现任何文字、数字、印章、签名」 |
| 元素太杂 | 「重画。只要一个主体，四周留白，不要背景杂物」 |
| 人物太美型 | 「重画。要真实的中年人，脸不好看也没关系，要憔悴」 |
| 竖图被画成横图 | 「重画。我要竖的，高比宽长」 |
| 整体太亮 | 「重画。压暗，最亮只到中灰，大面积留深色」 |

一般一两条就能调到位。不满意就说「重画」，它会记住同一对话里的参考图。
