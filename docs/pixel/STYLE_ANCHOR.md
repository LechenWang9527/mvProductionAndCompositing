# 像素风 MV · 固定风格与全局结构

> 2026-11-21 定稿。此后所有镜头共用本文件，不再逐条商量风格。

## 一、画面语言（固定不变）

- 语言：old 8-bit video game cutscene，不是电影、不是 3D。
- 分辨率感：逻辑画布约 256×144，所有边缘阶梯状，所有像素是大方块；屋顶、窗光、灯笼都是「大方块簇」，没有细碎细节。
- 色板：near black `#0d0d14` / deep indigo `#1a1a2e` / dark brown `#3a2a20` / dull red `#8c2f24` / amber `#d98a30` / pale cream `#e8dcc0`。
- 光：永远是「硬的、平的、琥珀色块」，**不许叠渐隐光晕、不许 bloom**。
- 建筑：只有中国古建 —— 飞檐、瓦顶、塔、城墙垛口、红灯笼。不许欧式城堡、尖塔、现代楼（现代段除外，见下）。
- 人：**只给背影、剪影、小小的人形**，永不露正脸、永不画五官。
- 画面内**绝对不放文字**（含招牌、匾额、字幕）。字幕后期加。
- 相机：**永远向右**（时间前进方向）。过门时可横移，事件发生时可定格或极缓慢推进。不许摇晃、不许快速变焦、不许旋转。

## 二、一条贯穿全片的规则

**镜头永远向右走；横移＝赶路（过门），停下＝有事发生（关卡）。**

超级马里奥的阅读方式：跑 → 遇到关卡元素 → 互动 → 继续跑。
所以「横移」和「停留」就是本片的呼吸：**段间用横移，段内事件用停留**。

## 四、统一符号

- **斗篷**：你＝暗红；杜甫＝青灰；刘邦＝赭红。所有人只有背影。
- **灯**：每段至少一盏，位置永远在画面右边（前方）。
- **脚印**：走过的路留有微光脚印，是「有一千个人先走过」的证据。
