## 时间锚（第二版，按用户反馈调过）
| 时刻 | 事件 | 依据 |
|---|---|---|
| 23.357 s | 路面开始从脚下铺出 | 巷景出现的时刻（`ALLEY_START`）。**不能放在 24.663**：那一刻进度是 0，线头贴在画面最下缘，画面上等于没有线 |
| 24.663 s | 「我是来陪你走这一程」唱出 | 此时路已可见一截，正处于往远处匀速生长中 |
| 27.93 s | 路面铺到灯下，同时路灯亮起 | 「前面有我留的灯」起点 |
| 29.5 s | 灯稳定 | 场景收束 |
| 30.4 s | 场景切换 | V4 原有 `DUFU_TRANSITION` |

铺路总时长 4.573 s，进度曲线 `drawEase = 0.72·t + 0.28·smoothstep(t)`：以匀速为主、两端轻缓。
**不要用纯 `smoothstep`**——它导数在中点最大，读感是「先憋一下再窜出去」，正是用户说的「直接就延伸了」。

## 几何（量出来的，别凭感觉调）
巷子底板 `assets/chorus-v3/alley-lamp.png` 是 1672×941，`objectFit: cover` 到 1920×1080（缩放 ≈ 1.148）。
- **地平线 y ≈ 570**。第一版把远端收到 y=521（地平线之上）→ 线「往天上收」，被判不合格。
- 路灯灯头 `ALLEY_LAMP_HEAD = { x: 1314, y: 338 }`，灯柱基座约 `(1314, 720)`。
- 两条边线：`P0 = (250,1150) / (1700,1150)`（在画面外），`P1 = (700,880) / (1520,880)`，`P2 = (1235,583) / (1279,583)`（远端收在地平线下方一点）。
- **曲线穿过画面底边 y=1080 的参数点 `T_ENTER = 0.1287`**（de Casteljau 细分求的）。路径只画 `T_ENTER→1` 这半段，否则前 0.6 s 画出来的线全在画面外。
- 笔尖与石板缝都用 `toCurveT(p) = T_ENTER + p·(1-T_ENTER)` 换算回整条曲线参数，否则笔尖会跑到画外、缝会错位。
- 生成带 100 px 坐标网格的底板图：`python analysis/alley_grid.py` → `out/v4scroll_check/_alley_grid.png`。

## 质感：亮层 screen + 暗层 multiply
高对比不是靠把线调白，而是靠**两层反向混合**：
- 暗层 `mixBlendMode: multiply`：`stroke="#1a120c" strokeWidth={11}` + `feGaussianBlur stdDeviation=2.6`，作为路缘凹槽（灯照亮的地面上必须有暗边，否则亮线会被暖光吃掉）；
- 亮层 `mixBlendMode: screen`：外亮层 `strokeWidth 4.8`（渐变 0.74→0.11）+ 内芯 `strokeWidth 1.6`（0.55→0.08）+ 12 px 光晕；
- 整组过 `feTurbulence`(baseFrequency .013, seed 11) + `feDisplacementMap(scale 2.6)` 手绘抖动。

## 四代迭次与教训
1. **第一版**：远端收在 y=521 + 横贯等距石板缝 → 读成「白色霓虹三角」和「铁轨枕木」。
2. **第二版**：远端降到 y=583、横缝改单侧短划、加抖动、`screen` → 成立，但仍太淡。
3. **第三版**：线宽 2→2.8、渐变抬亮 45% → **用户发回截图：「跑道感」**。
4. **第四版**：石板缝左右交替、长短不一、间距不均（`SEAMS=[{t,len,side}]`），每条单侧短段；线色改暖金。
5. **第五版（当前）**：路径裁到画面底边（从脚下起笔）、起点提前到 23.357、进度改线性为主、亮暗双层混合。

三条硬教训：
- **两侧对称等距的短横线，人眼一律读成跑道/机场边灯。** 想读成「路」，必须不对称：左右交替、长短不均、间距不等。
- **曲线的近端如果放在画面外，前几帧画出来是空的**，观感是「突然窜出来」而不是「从脚下长出去」。必须裁到画面边缘。
- **「慢」不能靠把时长拉长**——`smoothstep` 拉长后中段仍然快。要换缓动曲线。

## 已知可再调的地方
- 线条现在是「工艺制图」的克制感；若想更接地，可给亮层再叠一点 `feTurbulence` 的晕（scale 2.6 → 4.0），代价是干净感。
- 石板缝目前只沿路两侧各 9 条；如果要「更像石路」，可在路中心补 2–3 条极淡的横向接缝（但注意别回到「枕木」）。
