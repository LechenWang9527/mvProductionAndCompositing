> 结论先行：**全片 87 镜里有 78 镜程序已经能画得很好，只有 5 镜真的画不像；真正缺的不是「厂房」，是「人」和「实物」。**
> 你要的「视觉更丰富」，最省力的做法不是替换掉现有版式，而是**把照片当作底图层垫在已有版式下面**（版式不动，底下多一层材质/空间）。这样 87 镜的节奏、时间码、歌词卡点全都不用改。

## 1. 判据：程序画得出来 vs 画不出来

Canvas2D 的强项和弱项非常清楚，不是能力问题，是「值不值得」问题。

| 画得出来（且是强项） | 画不出来（或画出来很假） |
| --- | --- |
| 横平竖直的线：网格、表格、坐标轴、柱状、折线、雷达、流程节点 | **有机曲面**：轮胎断面、胶料堆积、人脸、手、人体 |
| 排版：大字、逐字显影、字距压缩、反白、竖排 | **真实材质**：木纹、纸纤维、锈、油污、粉尘、磨损 |
| 卡片 / 工牌 / 名牌 / 灯箱 / 档案卡 / 印章 | **空间纵深**：厂房内部、产线往远处消失 |
| 终端、ASCII 字符场、代码、日志 | **复杂实物**：钥匙串、酒爵、泡面碗、手机 |
| 蓝图线稿、剖面图、尺寸标注 | **光影**：侧逆光、硬阴影、光晕渐变（能做但要假） |

一句话：**「字」和「图表」程序画得比 AI 好；「物」和「人」AI 比程序好。**

## 3. 三个必须说清的事

### 3.1 现有 8 张图里，有 4 张是「没用上」的

程序只接了 **P01（#25）／P04（#66 #70）／P05（#83）／P08（#35 #83）** 四个。
**P02（轮胎断面）、P03（混炼车间）、P06（纸纹）、P07（工牌）** 目前在片子里的**消费方是零**——因为分镜里这四镜本身都是程序画的图表/版式。

想让它们有用，有两条路：
- **保守**：把 P02/P03 当**底纹**（低透明度垫在 #62/#57 的蓝图下面），P06 垫在 #39/#6 下面，P07 垫在 #37/#52/#72/#79 的工牌照片窗里。**只要改 shotfilm.js 加 `photo:` 参数，不新增镜头。**
- **激进**：新增镜头，专门给厂房。

### 3.2 厂房在现在的分镜里**没有位置**

你说「厂房啊、产线啊画不出来」——对，但**现在的 87 镜里没有任何一镜是拍厂房的**。车间只在 #57 出现过，而那镜是「胶料配方工程图」，是蓝图不是实景。

所以「上厂房」不是「替换某镜」，而是**加镜**。加镜会动到 305.9 s 的总时长和整条节奏曲线（每条切点都跟 `og_timing.json` 对齐），代价比换图大一个量级。

**建议**：这一轮不加镜。厂房图先当**底图层**用（#57 蓝图下面垫一张低透明度的混炼车间），观众能感到「后面有车间」，但版式和时间码一个都不动。等你看过效果再说要不要真加镜。

### 3.3 「历史人物肖像」跟现有的硬规则冲突

`film/docs/STORYBOARD.md:24` 写死：

> **全局规则·人**：12 位同事只用姓名条 / 工牌 / 编号 / 剪影，全片零人脸、零真人照片、零外部图片。

这条规则的**本意是保护 12 位真实同事**（不侵犯肖像权、不做真人照片）。我建议这样切：

| 谁 | 怎么做 | 依据 |
| --- | --- | --- |
| 12 位真实同事（曹教授/吴晗/传勇/Gary/Allen Ma/小马…） | **仍然零人脸**，只有名牌、工牌、编号、剪影 | 原规则不动，保护真人 |
| 古代人物：杜甫、刘邦 | **可以出木刻/版画肖像**，但只做版画语言，不做照片 | 死了 1000 多年，无肖像权；且木刻是这支片子的原生语言 |

这样既满足你「画一下他们的肖像」，又不破「不拿真人脸做图」的底线。**这条需要你点头。**

## 5. 如果要接，改哪里（不动 film/ 下任何 .js 的话到此为止）

接一个槽位只需要两步，都不碰渲染逻辑：

1. 图放进 `film/media/photos/P09.jpg`，在 `film/media/photos/manifest.json` 加一行 `"P09": "P09.jpg"`。
2. 在 `film/src/shotfilm.js` 对应镜的 `p` 里加 `photo: 'P09'`（可选 `photoAlpha` / `photoScrim` 控制浓淡）。

**但第二步是改 .js**。上一轮的硬约束是「不要动 film/ 下任何 .js」，所以现在**卡在这里，等你授权**。

另外还有一件已知问题等你拍板：`film/src/photo.js:52` 的
```js
g.filter = 'grayscale(1) contrast(1.18) brightness(0.94)'
```
加上后面「乘近黑 → 叠 55% 骨白」的两步，会把任何照片压进 0.52–0.54 的窄带（实测 #25 桌面动态范围 82 → 31）。**这就是你说「质感不行」的主因**，不全是图的问题。修法是按亮度在纸色/墨色之间插值，但这个也是改 .js。
