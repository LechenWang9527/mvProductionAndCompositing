# 怎么用 ChatGPT 出这几张图 —— 一步步来

不用懂提示词，也不用懂代码。你只要会**复制、粘贴、另存为**就行。
全程大约 20 分钟（不含 ChatGPT 排队出图的时间）。

配套文件：
- [PROMPTS_CHATGPT.txt](PROMPTS_CHATGPT.txt) —— 拼好的 8 条英文，直接复制
- [refs/style_ref/](refs/style_ref/) —— 6 张风格参考帧
- [refs/slot_frames/](refs/slot_frames/) —— 11 张镜头参考帧

---

## 第 0 步：先想清楚你要的是「照片」，不是「截图」

这 8 张图会被塞进 MV 的 8 个空位里，程序然后自己往上画字、画线、画页码。

所以两条铁律：

1. **图里不能有字。** 文字、页码、标题、水印、logo 全部由程序画。AI 画的字一定是鬼画符。
2. **图不能有滤镜感。** 不要暗角、不要边框、不要鲜艳色、不要「电影感」调色。程序后面要统一上双色调和纸纹，你提前染一遍就脏了。

这两条记住了，剩下的就是机械操作。

---

## 第 1 步：打开 ChatGPT，新建对话

1. 浏览器打开 `chatgpt.com`，登录。
2. 左上角点「新对话 / New chat」。
3. 确认用的是能出图的模型（GPT-4o / GPT-5 之类，免费账号也能出图，每天张数有限）。

> **8 张图都在同一个对话里出。** 同一个窗口，ChatGPT 会记住前面的调子，8 张才像一套。中途别开新窗口。

---

## 第 2 步：先发「总纲」（只发一次）

打开 [PROMPTS_CHATGPT.txt](PROMPTS_CHATGPT.txt)，最上面有一段标着 **【总纲】** 的中文，整段复制粘进对话框，回车。

ChatGPT 会回「明白了」之类。**这一步不出图**，只是先把整组的调子定下来。

---

## 第 3 步：出第一张（P01 桌面）—— 两种做法，选一种

### 做法 A：只发文字（最省事，先试这个）

复制 `PROMPTS_CHATGPT.txt` 里 **P01** 那一条英文（从 `Shot like` 开始，到 `Plain photographic image only.` 结束），整条粘进对话框，回车。

> P08 那条结尾不是这句，而是 `no other text, no watermark, no border, no UI, no vignette.` —— 照它自己的结尾复制完就行。

等 30–60 秒出图。

### 做法 B：发文字 + 带上参考图（更像这一套）

图片来源：`docs/refs/`，直接用，不用处理。

**上传方法：**

1. 在 ChatGPT 输入框左边找 **「＋」或回形针 / 图片按钮**，点它 → 选「上传图片 / Upload from computer」。
2. 选这两张（一次最多传两张，别多）：
   - 风格帧：`docs/refs/style_ref/S6_marpol_L36_blueprint.jpg`（暖纸底那张，定色调）
   - 槽位帧：`docs/refs/slot_frames/P01_shot25_phone_desktop.jpg`（定这块空位在画面里的位置和明暗）
3. 图上传完后，**在同一个输入框里**再粘 P01 那条英文，然后**在这条英文后面补一句中文**（这句很关键）：

```
参考上面这张图的色调、光线方向和颗粒感。但不要照抄图里的文字、横线、边框、
页码和版式 —— 我要的是这张照片本身，不是这张截图。图里不要出现任何文字。
```

4. 回车。

**为什么要补这句**：参考帧里全是程序画的字和线，你不明确说，ChatGPT 会连字一起复制过去。

## 第 7 步：告诉程序「我放了哪几张」

在 `film/media/photos/` 里新建文本文件 `manifest.json`（后缀是 `.json` 不是 `.txt`），记事本打开，把下面内容贴进去，**只留你实际放了的行**：

```json
[
  { "id": "P01", "file": "P01.jpg" },
  { "id": "P04", "file": "P04.jpg" },
  { "id": "P05", "file": "P05.jpg" },
  { "id": "P08", "file": "P08.jpg" }
]
```

保存时编码选 **UTF-8**。少写哪张就等于告诉程序「这张还没有」，它会自己用图形版，不报错。

> 这一步只碰 `film/media/photos/` 这个素材文件夹，**不要动 `film/` 里的任何 `.js`**。

## 出歪了怎么办（照着发中文就行）

| 问题 | 你就发这句话 |
|---|---|
| 图里有字 / 水印 | 「重画，画面里不要任何文字、字母、数字、水印、logo，只要纯照片」 |
| 把参考图里的版式抄过来了 | 「不要照抄参考图的版式和文字，只要它的色调和光线，画一张纯照片」 |
| 像插画 / 3D | 「重画，必须是真实相机拍的照片，不要插画感、不要 3D 渲染」 |
| 颜色太艳 | 「重画，颜色再压灰一点，低饱和，不要鲜艳」 |
| 太亮太干净 | 「重画，更旧一点，多点磨损、灰尘、划痕」 |
| 冒出人脸 / 手 | 「重画，画面里不要出现任何人、手、人影」 |
| 比例是方的 | 「改成横构图 16:9」（P06 说「竖构图 3:4」） |
| 出了 4 张拼图 | 「只要一张，不要拼图，不要四宫格」 |
| 参考图是暗底，结果太黑 | 「不要照抄参考图的暗度，调亮到能看清结构，保持暖灰」 |

**ChatGPT 拒画马牌 logo**（商标，很常见），别硬争，换成这句：

> 「不要出现真实品牌，改成一个磨损的黄色圆形旧招牌，上面只有一个马的剪影，没有任何字母。」

## 三个小疑问

**Q：出来的图是正方形的，能用吗？**
能用。程序会按槽位自动裁切铺满。只要构图对、主体在中间，差一点不影响。

**Q：下载下来是 `.webp`？**
用「画图」打开 → 另存为 → JPEG 图片。或者 manifest 里直接写 `.webp` 也行。

**Q：一张都不满意，能不能不做？**
能。这几张是锦上添花，不放图片子照常渲，只是桌面、产线、马路这几处会显得空。

## 一句话总结

**同一个对话里：发总纲 → 传 1–2 张参考图 → 粘一条英文 → 补一句「只要色调不要文字」→ 出图 → 下载改名 → 丢进 `film/media/photos/` → 回来喊我。**
