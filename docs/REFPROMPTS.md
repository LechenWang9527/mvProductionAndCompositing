**提示词要点**

- **L36 蓝图**：只有蓝和白，**蓝只在明度上变**（涂层、污渍、折痕），白只在粗细和软硬上变、绝不换色相；白线主轮廓约画宽 `1/600`；**唯一一个非蓝颜色只用一次**——印章墨（红最经典，绿 APPROVED / 黑 VOID）承担判决；手写字用 Architects Daughter、标题栏字段用 B612、签名才用 Allura；文字像笔尖发光一样从左到右写出来；字幕做成「图注」压在独立 overlay 上（预乘 alpha），别画进墨层。
- **O30 青晒图**：图纸铺满画面，普鲁士蓝 `#143874` 斑驳、曝光不匀、边缘过曝发绿，有折痕和水渍；白线 `#ECF4FF` 锐利但「是印出来的」——轮廓约画宽 `1/600`、剖面线与尺寸线减半、曝光弱处断续、带几像素青色微晕；用制图语法把主体画密：立面、剖面、详图圈、尺寸链、虚线、单线工程字、标题栏；批注和动作用**红铅笔 `#D63426`**；唯一手绘上色的主角要放大到 ≥ 画高 `1/5`、不透明水粉、一种暖色分几个深浅，其余全画不能有暖色。
- **O70 蓝图→3D**：蓝图只占开头 **1–2 s、不超过全片 15%**；普鲁士蓝 `#12306B → #244D8F`、白棱线约画宽 `1/800`、被挡的线画虚线、人物地形用等高线；滑动变焦让立面立成透视，再从主角往外显出全彩，**显影边是带暖光的软边**、幽灵线 1 s 内淡掉；之后金时刻 3D：低太阳、琥珀高光 `#F2B860`、深暖阴影 `#3A2530`、水面碎金、薄雾、浅景深、轻泛光、细颗粒；一个不间断运镜。
- **L16 档案灯箱**：中性冷白灯箱 + 档案自身的色调，**不要给档案重新调色**；**一个信号色**（如信号橙）只给标记、读数、锚点、判决，绝不铺在图片背后；等宽体 IBM Plex Mono 17–34 px 做编号/日期/读数（读数 74–120 px），无衬线 21–36 px 做标签，衬线 60–76 px 只给标题；放大镜内部**不超过 1.5 屏幕像素 / 扫描像素**；放大镜要「落」在物件上，不要滑过空桌。
- **O88 缩微胶片**：四色网角 `15°/75°/0°/45°`、网点约画宽 `1/250`、套色错 1 px；整幅压成低反差磷光绿：片基 `#1b2320`、帧间隙 `#0c110f`、高光不超过 `#a0dcaf`；**每 3 px 一条扫描线**、每 4 s 滚过一道淡扫描带、一块柔和灯斑、玻璃上有灰和一根头发、圆角遮光罩只压外圈 5%；换场让胶片横向滑过暗色帧间隙 0.5 s。

## ③ 15 个通用技法（不是风格，是积木）

> 全部给 Canvas2D 口径。`c` = ctx，`w/h` = 逻辑宽高，`t` = 秒，`s` = 状态对象。

### 3.1 半调网点（halftone screen）
把明暗换成点径，是整套印刷感的根。45° 网格，点径 = `r0 * sqrt(1 - lum)`，亮部点缩到 0。
```js
const ang = Math.PI/4, step = Math.min(w,h)/250;      // 网点约画宽 1/250
for (let y=0; y<h; y+=step) for (let x=0; x<w; x+=step) {
  const u = (x*Math.cos(ang) - y*Math.sin(ang))/step;
  const v = (x*Math.sin(ang) + y*Math.cos(ang))/step;
  const lum = sampleLum(x, y);                         // 0..1
  const r = (step*0.62) * Math.sqrt(1 - lum);
  c.beginPath(); c.arc(x, y, r, 0, TAU); c.fill();
}
```
**两版套印**：同一函数跑第二遍，换角度（15°/75°/0°/45°）和颜色，整体错 1–3 px。

### 3.2 双版错位套印（misregistration）
印刷感的 90% 来自「对不齐」。同一层画两次，第二层偏移 + `multiply`。
```js
c.globalCompositeOperation = 'multiply';
c.save(); c.translate(2, 3); drawPlate('#C82C28'); c.restore();   // 偏 2–3 px
c.globalCompositeOperation = 'source-over'; drawPlate('#1E1B1E'); // 黑版最后压
```
**铁律**：偏移量**每镜固定**，只在重拍上踢一下；逐帧随机 = 闪。

### 3.3 遮罩擦除（mask wipe）
字幕/图像「印」出来、网点从中心铺开、放大镜里显影，都靠它。
```js
c.save(); c.beginPath(); c.arc(cx, cy, R*eOut((t-t0)/.28), 0, TAU); c.clip();
drawContent(); c.restore();
```
反向（擦掉）用 `globalCompositeOperation='destination-out'` 画形状——但**只在离屏 canvas 上用**，别在会被上传的层上做反白。

### 3.4 油墨外扩（blur + threshold）
「印」而不是「画」的关键：先画清晰，再模糊 1 px，再按噪声阈值切边。
```js
octx.filter = 'blur(1px)'; octx.drawImage(src, 0, 0); octx.filter = 'none';
const d = octx.getImageData(0,0,W,H), n = noiseField(W,H,seed);
for (let i=0;i<d.data.length;i+=4){ const a = d.data[i+3] + (n[i>>2]-.5)*90;
  d.data[i+3] = a > 128 ? 255 : 0; }        // 边缘毛糙 + 局部缺墨
octx.putImageData(d, 0, 0); c.drawImage(oc, 0, 0, w, h);
```

### 3.5 字符场采样（ASCII field）
```js
const CH = ' .,:;-=+*#%@', cs = Math.max(7, Math.min(w,h)/26);
const cols = Math.floor(w/(cs*.62)), rows = Math.floor(h/cs);
c.font = `500 ${cs}px ${MONO}`;
for (let j=0;j<rows;j++) for (let i=0;i<cols;i++){
  const k = Math.floor(clamp(lum(i,j),0,.999)*CH.length); if(!k) continue;
  c.fillText(CH[k], i*cs*.62, j*cs);
}
```
用途：终端字幕底纹、字的隧道、故障前的「信号衰减」。

### 3.6 等值线（marching squares）
蓝图、地形、心跳、'心里的等高线' 都是它。库里 C3 有完整实现（60 列网格、5 个移动高斯、11 级、case 表 16 项、第 6 级加亮）。
```js
const idx = (a>lv?8:0)|(b>lv?4:0)|(e>lv?2:0)|(d>lv?1:0);   // 四角 > 阈值
if (idx===0||idx===15) continue;
const seg = {1:[Lf,B],2:[B,R],3:[Lf,R],4:[T,R],5:[Lf,T,B,R]}[idx];
for (let k=0;k<seg.length;k+=2){ c.moveTo(...seg[k]); c.lineTo(...seg[k+1]); }
```
**每级一个 lineWidth**，主线加粗一倍并换色，就是「图纸」而不是「等高线图」。

### 3.7 图表生长（stagger + eOut）
```js
const e = eOut((tm - .2 - i*.25)/.8);        // 每根错开 0.25 s
c.fillRect(x, bot - hgt*e, bw, hgt*e);
c.fillText(Math.round(v*e), x + bw/2, bot - hgt*e - fs*.5);
```
柱子跟拍子走、数字跟着柱子走，**不要整屏一起长**。

### 3.8 描边生长（setLineDash）
线稿自己画出来（蓝图、一笔画、关系图箭头）。
```js
const L = pathLen;                                   // 预先算好
c.setLineDash([L*e, L]); c.lineDashOffset = 0; c.stroke();
```
比逐点 `lineTo` 便宜得多，且天然可逆（倒放 = 擦掉）。

### 3.9 纸张颗粒（pattern + multiply）
```js
const pat = c.createPattern(paperTex(w,h,dpr,base,seed), 'repeat');
c.globalAlpha = .5; c.globalCompositeOperation = 'multiply';
c.fillStyle = pat; c.fillRect(0,0,w,h);
c.globalCompositeOperation = 'source-over'; c.globalAlpha = 1;
```
纸纹**每镜一换就不真实**——同一场景共用一张，只挪 offset。`paperTex` 在 `_公共函数.js` 里有现成实现（每 40 px² 一个暗/亮点 + 0.6 px 纤维短线）。

### 3.10 故障三件套（RGB 分离 / 切片位移 / 扫描线）
```js
c.globalCompositeOperation = 'lighter';
c.fillStyle = '#ff2b2b'; c.fillText(txt, cx - dx, cy);
c.fillStyle = '#00e1ff'; c.fillText(txt, cx + dx, cy);
c.globalCompositeOperation = 'source-over';
if (burst) for (let k=0;k<7;k++){
  const y = Math.random()*h, sh = 4 + Math.random()*h*.08, off = (Math.random()-.5)*w*.12;
  c.drawImage(c.canvas, 0, y*dpr, c.canvas.width, sh*dpr, off, y, w, sh);  // 自己切自己
}
for (let y=0;y<h;y+=3){ c.fillStyle='rgba(0,0,0,.22)'; c.fillRect(0,y,w,1); }
```
`burst` 用**时间窗**控制（比如 1.2–1.7 s、3.1–3.3 s），不要概率触发。

### 3.11 打字机时间轴
```js
// 预计算一次：[t, str] 序列；播放时只做一次线性/二分查找
let tt=0, str=''; const st=[[0,'']];
for (const [k,v] of ops) { if(k==='type') for(const ch of v){ tt+=.17; str+=ch; st.push([tt,str]); } … }
```
好处：**完全确定性**，`renderAt(5.3)` 与实时播放结果一致。光标闪烁用 `since < .45 || floor(t*1.8)%2===0`。

### 3.12 拍二抖动（boil on twos）
手绘/版画每 2 帧换一次形，才有「帧」的呼吸。
```js
const tq = Math.floor(t*12)/12;        // 12 fps：角色抖动用这个
const tc = t;                          // 24 fps：镜头/粒子用这个
```
**只抖角色和道具，别抖文字和网点**，会糊成一团。

### 3.13 视差分层（parallax layers）
剪纸、纸剧场、档案堆叠都靠它：层间位移不同，层内不做透视。
```js
layers.forEach((L,i) => { const off = t * (6 + i*10) * m/300; drawWave(L, off); });
// 阴影：shadowColor + shadowBlur 10 + shadowOffsetY -3
```

### 3.14 确定性随机（seeded rng）
导出契约的命门。任何「看起来随机」的东西都必须可重放。
```js
function rng(seed){ let a = seed>>>0; return () => { a = (a + 0x6D2B79F5)>>>0;
  let t = a; t = Math.imul(t ^ (t>>>15), t|1); t ^= t + Math.imul(t ^ (t>>>7), t|61);
  return ((t ^ (t>>>14))>>>0)/4294967296; }; }
```
**禁用 `Math.random()`**：G2/G1 这类样片自己用了，照抄时要换成 `rng(seed + frameIndex)`。

### 3.15 刀痕飞白（taper stroke）
木刻/铜版的「一笔」要有钝进尖出和崩口。
```js
function cut(x0,y0,x1,y1,wid,seed){          // wid 沿线渐变，尾端收到 0
  const n = 8, r = rng(seed);
  for (let k=0;k<n;k++){ const u=k/n, ww = wid*(1-u)*(0.8+r()*0.4);
        c.lineTo(lerp(x0,x1,u) + (r()-.5)*1.2, lerp(y0,y1,u) + (r()-.5)*1.2);
        c.lineWidth = ww; c.stroke(); }
}
```
刀宽三档（轮廓 / 排线 / 大刻）不要混成一个值——混了就变钢笔。

## ④ 6 条导出硬规则（复述自 `references/rendering.md`）

| # | 规则 | 原文依据 | 落地检查 |
|---|---|---|---|
| **1** | **只有一个时钟**：页面必须暴露 `window.renderAt = async (t) => {…}`，`t` 是秒，动画/粒子/相机/字幕全部按这一个时刻求值 | 「把所有动画、粒子、相机、字幕定位到这个时刻」 | 任意跳帧调用都出同一画面 |
| **2** | **`?export=1` 必须停机**：不启动 `requestAnimationFrame`、不设计时器循环、停掉 CSS 自播放动画，由 `renderAt(t)` 唯一推进 | 同上 | URL 带参数时画面静止，只有 renderAt 能改它 |
| **3** | **随机必须可复现**：粒子在启动时用固定种子生成，或直接由索引 + 时间算出 | 「随机粒子启动时用固定种子生成」 | `Math.random()` 在绘制路径里出现 = 违约 |
| **4** | **异步资源在 renderAt 返回前就绪**：字体、图片、纹理、JSON 都要在第一次返回前完成加载 | 「异步资源应在 renderAt 返回前准备好」 | 首帧不能字体回退、不能空白 |
| **5** | **尺寸三合一**：Canvas 像素尺寸 = CSS 视口 = 输出尺寸，不带播放器控件 | 「Canvas 的像素尺寸、CSS 视口与输出尺寸一致」 | 1080p 就是 canvas 1920×1080 且 CSS 同尺寸 |
| **6** | **导出命令固定**：`python <技能目录>/scripts/render_video.py ./index.html --output ./output/video.mp4 --duration 12 --fps 30 --width 1920 --height 1080`，尺寸必须为正偶数，帧数 = `ceil(duration × fps)`，先导短段再导全片 | 导出章节 | 依赖：`playwright` + `chromium` + PATH 里的 `ffmpeg`；资源必须放在 HTML 同目录或子目录（本地 HTTP 服务只服务那里）；脚本**不生成声音**，`--audio` 只是配上，默认无声，输出已存在会拒绝覆盖 |

## ⑥ 给主控的三条建议

**1）按「四套调色板 × 三种植物质感」建风格池，不要按系列建。**
`ancient` 只从 L30 / O3 / O60 / L31 里选（木刻 + 工笔 + 铜版），`marpol` 只从 O22 / O40 / L28 / H5 里选（活字 + Riso + 工业报），`system` 只从 L36 / O30 / L16 / L33 里选（蓝图 + 灯箱 + 瑞士网格），`terminal` 只有一条线（L39 / X14 / E3）。跨池借用必须换墨色，否则四个段落的「印刷语言」互相污染，观众会觉得是四支不同的 MV。

**2）0.9 秒一拍的密度，靠「同风格内换机位」而不是「换风格」。**
O 系列每条都自带分镜秒数（0.8–0.9 s/镜），L30/O19/O22 这些的镜头语法是「小推 / 横移 / 重拍一震 / 切详图」——同一个风格连切 4–6 个机位，比 4 个风格各来一刀更稳。真正需要换风格的位置只有：hook（A3 大字）、07 ledger（O18 打字机或 O88 胶片）、22 finale（O70 蓝图显影）。其余段落让它一直待在一种材质里。

**3）先拿 A–G 的 26 段代码当骨架，再往上贴 L/O 的皮肤。**
`_公共函数.js` 已经给了 `rng / nz / eOut / eBack / offscreen / paperTex / glowDot / mixHex`，E3（字符画）、F1（图表生长）、C3（等高线）、G2（故障）、A2（打字机）、E2（视差）、B1（流场）都是能直接跑的函数体，签名统一是 `(c, w, h, t, s, dpr)`。正确顺序是：**先让 A–G 的代码跑起来 → 换调色板 → 把 O/L 的 hex 和线宽套上去 → 最后加 L30/L29 的字幕规则**。反过来（先抄英文 prompt 再找实现）会得到一堆没法导出的漂亮描述——库里 145 条无静帧、45 条才有代码，这个比例本身就是警告。
