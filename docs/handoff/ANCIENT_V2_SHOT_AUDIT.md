# 古代段 V2 镜头清点（#1–34）

## 口径

- 镜头区间取 `film/data/shots.js`；歌词原文和每句起止取 `lyrics/og_timing.json`。表中歌词时间保留原时间轴，不按镜头边界截短。相邻句跨镜、镜头时长与歌词时间略有错位时均照录。
- 当前 layout 以 `film/src/shotfilm.js` 的 `PLAN` 及实际注册 layout 的源码为准；素材 ID 由 `film/src/photo.js` 的候选素材/生成素材清单解析。这里只做静态源码清点，没有启动浏览器或逐帧检查素材是否成功加载。
- `film/data/shots.js` 的 `style / subject / action` 描述与当前 `shotfilm.js` 执行计划存在多处差异，不能直接当作现在画面的说明。例如 #1–2 描述为终端/抽屉，但执行计划使用 `preludeLamp`；#10 描述逐把生成钥匙，实际使用单张 `KEYS_BADGE_LINE_V1`；#13 描述泡面碗，实际使用桶装面素材；#32–34 描述字符风/木刻数字/档案格，实际走 `windExperience`。下表的 layout 与素材按渲染源码记录。
- `og_timing.json` 中 #34 的最后一句到 **137.259s**，而古代 demo 镜头 #34 在 **136.900s** 结束；歌词原文与时间未作修改。
