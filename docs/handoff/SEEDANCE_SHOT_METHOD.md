# 《The OGs》Seedance 分镜方法

先确定一个镜头让观众看见什么变化，再给它所需的参考图。Seedance 生成画内画面的运动。原曲、落词、两镜之间的切点、三行字幕和舞台超宽构图由本地剪辑负责。以原曲 00:23.357–00:33.065 的「小巷接杜甫」作为首轮验证区间。

## 参考图怎么交

| 想固定什么 | 交给模型什么 | 模式 |
|---|---|---|
| 当前镜头的布局、取景和开场状态 | 一张完整定稿画面，比例与计划输出一致。画面里已摆好人物、场景和道具。 | `first_last_frame`，一张首帧。适合稳住构图后让风、衣袖、蒸汽等动起来。 |
| 开场和收尾的两个确定状态 | 两张同尺寸、同机位、同景深的定稿图。亮灯镜头只改变灯和受光处，门、砖缝与灯杆对齐。 | `first_last_frame`，按首、尾顺序传。 |
| 人物外观、环境或画风，镜头有自由度 | 从场景图、人物图、光色图中挑需要的，先用一到三张。逐张写清提取哪部分。 | `m2v`。引用可以引导画面，构图和动作需看实际输出。 |
| 同一空间里延续上一镜的运动 | 优先用上一条稳定的末帧接首帧。相机仍在移动时，可试用合格的前段短视频作运动参考或按模型能力续写。 | 逐次核对灯位、墙缘、画面运动方向和速度。新地点用其自己的定稿参考开镜。 |

小巷只用现有 `chorus-v3/alley-lamp.png` 就能试第一次。它负责**空间结构、石板材质和最终暖光**。杜甫的 `dufu_reference_v2.png` 负责脸、发式、衣领与衣料，画像里的坐姿不指定下一镜的动作；`changan_ink_v2.png` 是俯瞰城图，适合给建筑样式和水墨色调，租房镜头仍要定一张近景门廊构图。茅屋和风景各用自己的定稿背景，分别保持草顶结构和地平线。

上传后优先把图片放在同一即梦画布并引用其图片节点。即梦界面在正文用 `@图片` 指明作用；CLI 用 `--ref node:<图片节点ID>` 传实际素材，在正文用 `{{node:<图片节点ID>}}` 指清是哪一张图。首尾帧按参数槽位排序，保存后回读草稿的参考顺序。操作命令见[项目 CLI 操作单](JIMENG_CLI_SEEDANCE.md)。[即梦官方视频生成说明](https://bytedance.larkoffice.com/wiki/QO66wGahSiakEHkJbxIcNBtDnAc#BUQ6dfpfLoHIB0xbEtcceihenbe) · [方舟首尾帧与多模态参考规格](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。

## 指令怎么写

按这个顺序写：**各图负责什么 → 开场看到什么 → 相机怎么走 → 谁或什么发生变化 → 最后画面停在哪 → 哪几项必须保持。** 每镜设一个主变化和至多一个运镜。时间写片段内的秒数，作为动作节奏参考。原曲绝对时间另写在剪辑表上。把「有陪伴感」「电影感」翻成可以检查的动作，比如「近处石缝缓慢向画面两侧掠过，远处路口位置稳定」「暖光从灯罩扩到右墙，再落到湿石板」。官方示例也将参考对象分别指明，并按片段时间描述景别、动作和运镜。[Seedance 2.5 官方示例](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。

**小巷 A｜现有参考图，9 秒，16:9，720p，Seedance 2.5 多模态参考。**

> @图片1 负责巷子的砖墙、木门、石板透视、灯位和最后亮灯时的颜色。精细暖色水墨设色。单一连续镜头，视点沿中央石板路极慢前进，近处石缝缓慢移向画面两侧，远处巷口始终稳定。开头约两秒，低亮天光下看清近宽远窄的石路，灯罩未亮。接下来灯罩里逐渐浮出微暖的光，暖光先到右侧砖墙，再落到湿石板上。末尾暖光稳定，推进渐缓，留出约一秒可剪接的画面。空巷无人，砖墙、木门和灯杆保持原状。画内没有脚印、线条特效或文字。

**小巷 B｜只有 A 出现开场已亮、亮灯突变或建筑漂移才准备。** 以同一底图制作暗、亮两帧并对齐，使用首尾帧。把相机固定下来，只让灯芯、墙面与湿路面受光变化，先验证灯能否亮得慢且有层次。路的推进如果仍需要，可单独生成前半段，用 B 的暗帧当衔接构图。这样能判断问题出在参考图约束，还是同一镜同时要求推进和光线变化。

**杜甫下一镜｜先定木门旁的中景构图。** 人物位于灯光能照到的一侧，入镜时暖色亮区与小巷结束画面相近。先用杜甫画像固定脸、帽和领口，再用中景定稿作为首帧。视频给一个明确动作，比如「他在门前停步，手收进衣袖，抬眼向门内看」。保持侧面光向和服装细节，人物动作完成后留短暂停顿。小巷与杜甫分别生成，在原曲 **00:30.629「杜」附近**试切。

## 怎么决定保留还是返工

先看首、中、尾三帧排除硬伤，再把小巷与杜甫实剪在一起看原速。看得出路延向远方、灯有暗到亮的过程、墙门无形变、脸和衣服不漂、过切点时视线能被暖光接住，就进入下一轮。判断返工原因时，一次只改一类变量：

- **开场或收尾不对**：换成明确的首帧或首尾帧。亮灯过早时用暗帧约束开场。
- **动作顺序不对**：保留好参考，缩短指令、移走次要动作。先验证“灯罩 → 墙 → 地面”的次序，再加运镜。
- **构图或画风跑偏**：删掉作用冲突的参考，从定稿构图重新开镜。轻微亮度与色差留给调色。
- **单镜都好，接起来跳**：在原曲上前后挪入出点，选亮区、运动方向和视线更接近的帧。只补接不上的那一镜。

第一轮只验证小巷和杜甫，第二轮再用茅屋近景和大风远景试动。认可后按[古代段镜头表](SEEDANCE_ANCIENT_PRODUCTION.md)分批做。16:9 先验动作和画风，定正式取景前另验 4608×1152 主屏的主体大小和字幕区。当下只定制作方法，尚未提交生成。
