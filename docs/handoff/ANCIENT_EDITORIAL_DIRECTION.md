# 古代 demo：今晚的画面决策

2026-11-11。用户优先要求解决审美；Gemini 图生视频暂不等待，保留回填接口。以下是主负责人决定的实施标准，不代表用户已经认可改版。

画面像一卷由灯火照亮的水墨长卷。现有精细插画是场景本身，人物是画中的独立墨层；取消图片外的展板、统一缩略卡、重复标题栏、状态徽标和硬阴影。暖纸以明净为主，深夜使用真实灯桌的暗部，朱砂只用于时间经过与关键信息。统一打包的 Noto Serif SC / Noto Sans SC，杜绝系统回退造成的字体混用。

## 三种镜头语法

1. **场景**：城市、茅屋、众人居所、门锁、工牌、求人、泡面、战场、大风采用全幅插画或未来视频。禁止外加一层米色图片容器；不另加“长安/茅屋/战事序列”等解说标题。主物保持可辨，底部字幕区用柔和纸色或暗部过渡。画面可有受控取景与局部环境运动，不能把这些称作图生视频。
2. **纸面动作**：卷轴展开、数字落账、足迹式时间轴、消息发送有铺垫→动作→停留的过程。直接在画心发生；不套 dashboard。用真实生成素材做实物，用程序做文字、遮罩、时间关系和信息变化。
3. **人物**：杜甫/刘邦参考人物以大而完整的形象进入，名字只作为出场识别，避免人物被关在小相框里。古今联系通过同一条朱砂时间线与重复的灯火建立。

| 21.6–30 / 74.3–90 | 陪伴：人物/经历在同一纸面并置、汇合，最后落在同一盏灯。重复副歌有发展，不重复等尺寸卡列。 |
| 30–33.065 / 90–94.885 | 人物出场及身份：大人物与极少字号明确的身份信息；没有大字歌词重写。 |

## 验收

- 首先真实渲染短片，检查字体、遮挡、相邻镜头、字幕；静帧通过不能代替运动成立。
- 检查全部关键场景与所有切镜边界；原词、原时码、原曲不改。
- 输出独立新 Composition 与新视频，既有送审版不覆盖。
- 标明 Gemini 视频尚未回传，画面中的取景/蒙版/信息动画不冒称真实人物或场景运动。
- 1920×1080 是审看片；主屏4:1/三屏映射待负责人确认，禁止拉伸。

外部工具调查由子智能体完成，只有实际移植、渲染并看过的东西才记为已采用。今晚不以安装数量或模板名称充当画面质量证据。
