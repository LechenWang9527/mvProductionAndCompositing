## Opening 0–21.6s 的状态

| 歌曲时间 | 代码中实际变化；其余元素保持 |
|---|---|
| 0–0.28 | 纸底与未点亮的灯静止。 |
| 0.28–0.82 | 火焰显现；灯光扩散继续到 3.50s，灯位置不变。 |
| 3.50–7.40 | 卷轴展开；灯同步从 (650,250)/宽500 移到 (45,430)/宽245；右轴只做最多约 1.1°旋转。 |
| 7.40–8.05 | 卷轴、灯静止保持。 |
| 8.05–9.00 | 杜甫图淡入并上移；之后至 10.75 静止保持。 |
| 10.75–11.70 | 刘邦图淡入并上移；之后至 14.99 静止保持。 |
| 14.99–21.60 | 朱红时间线逐步绘出，圆点沿线走到右端；灯、卷轴、人物保持。歌词逐字染色由外层字幕组件完成，不在 `Opening` 内。 |

- 上表按 `AncientEditorialV3` 默认设置。`Opening` 默认 `enhancedMotion=false`，所以点亮后火焰/光效不持续呼吸；`AncientEditorialV4` 显式开启增强运动，会持续旋转火焰并脉冲灯光。两版的入场、展开、画线时码相同。
- 21.6s 后才开始人物靠拢与圆点回中；不要把该段动作算进 0–21.6s。
