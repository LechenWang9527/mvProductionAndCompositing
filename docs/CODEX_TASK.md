## 验收标准

1. `film/media/photos/` 下 8 张齐、命名 `P01.jpg`…`P08.jpg`。
2. 每张和 `docs/refs/gen_refs/` 里的帧放在一起看，**像同一套版**（同墨色、同网点、同纸纹）。
3. 画面里没有文字 / 水印 / 边框 / 人脸。
4. 抽一帧验：`node film/stills.mjs 110 240 290`，看 `out/stills/` 对应的三张，
   照片位不该是一块发灰的板。

## 备注：为什么要按帧出图，而不是给 prompt

上一版给的是「纪实摄影」提示词，出出来的图太写实 —— 有暗角、有光晕、有体积光、
有棚拍感，和全片的印刷版画语言冲突。帧本身就是风格定义，比形容词可靠。
