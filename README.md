# 《过来人 / The OGs》像素风 MV 制作与合成工程

本项目是年度主题曲 **《过来人 / The OGs》**（PE Annual Party）的完整 MV 制作、时间轴精准对齐与音画合成工程。

整部 MV 采用 **8-bit / 16-bit 复古街机像素风（1280×720 @ 24fps）**，以“**古代先贤（杜甫、刘邦）× 现代工艺人（必武、老曹、吴晗等一线团队成员）**”跨时空对话为主线，讲述跨越千年的坚守与共鸣。工程将 **AI 视频分段生成管线** 与 **FFmpeg 毫秒级定长剪辑脚本** 结合，解决了 AI 视频生成普遍存在的“单段时长固定、画风易漂移、多段拼接音画不同步”三大痛点。

---

## 一、项目核心作用与痛点解法

1. **统一标准歌词与时间轴解析**
   - 将甲方最新 LRC 与参考视频对齐解析，生成人类可读的分段歌词本（`lyrics/new_lyrics.txt`）、程序可读的结构化时间轴（`lyrics/new_timing.json`）以及无损剥离的官方母带音轨（`lyrics/PE_Annual_Party_新音轨.m4a`，总长 `04:34.21` / `274.21s`）。
2. **首尾关键帧接力，锁死像素画风**
   - 每一段 AI 视频生成前，提取上一段末尾最干净的画面作为下一段的首帧参考（存档于 `delivery_古代篇_20261122/03_关键帧/`），配合统一像素风约束提示词（`02_提示词/`），保证人物外貌、服装配色、夜空/庭院光影在几十个镜头间连续不跳戏。
3. **高精度定长裁切，彻底消灭音画漂移**
   - AI 视频模型每次只能吐出固定 `8.04s`、`9.02s` 或 `10.03s` 的片段，如果直接拼接，16 段下来会产生 **6 秒以上** 的累积音画错位。
   - `tools/check_and_stitch.cjs` 会按歌词节拍点对每段素材做精确到百分之一秒的定长裁切，统一重编码为标准 `24fps` `yuv420p` H.264 视频流，再与官方母带音轨无损混流并增加结尾淡出，实现**零累积漂移**。

## 二、标准制作工作流（5 步闭环）

```text
[1. 歌词与音轨基准] ──▶ [2. 拆段与关键帧锚定] ──▶ [3. 提示词与AI生成] ──▶ [4. 抽帧质检验收] ──▶ [5. 精准裁切与合片]
```

1. **提取最新时间轴与母带音轨**：放入甲方最新 `.lrc` 和参考 `.mp4`，运行 `node tools/extract_new_lyrics.cjs` 更新 `lyrics/` 基准（新版结构已调整为：`Hook1 ➔ 杜甫 ➔ Hook2 ➔ 必武 ➔ Hook3 ➔ 刘邦 ➔ 工艺人群像 ➔ Hook4 ➔ 大合唱`）。
2. **分段规划与首尾帧提取**：按 7~10 秒节奏切分镜头，从上一段合格视频的末尾抽取干净关键帧（避开模型末尾偶发抽风帧）。
3. **编写像素风提示词并生成素材**：遵循 `02_提示词/` 中的风格规范生成分段视频，合格的新版视频统一放入对应分段素材目录（废弃旧版移入 `_废弃旧版归档/`，严禁混用）。
4. **素材盘点与画质验收**：运行 `node tools/inventory_ancient.cjs` 盘点所有片段时长与完整性，对转场边界抽帧人工确认无破损、无画风丢失。
5. **批量定长裁切与音画总装**：运行 `node tools/check_and_stitch.cjs` 一键完成全部片段裁切、拼接与官方音轨合成。

## 四、如何快速跑起来

### 1. 前置环境
- **Node.js**：推荐 `v18+`（本项目验证环境为 `v26.13.0`）
- **FFmpeg**：脚本默认指向本地集成的 `ref_mv/node_modules/ffmpeg-static/ffmpeg.exe`；若新克隆仓库未安装 `ref_mv` 依赖，可在本机全局安装 `ffmpeg` 或在 `tools/*.cjs` 中把 `ffmpeg` 变量路径改为 `'ffmpeg'` 即可。

### 2. 常用一键命令

- **第一步：重新提取新版标准歌词、时间轴 JSON 与无损母带音轨**
  ```bash
  node tools/extract_new_lyrics.cjs
  ```
  > 产物将生成至 `lyrics/new_lyrics.txt`、`lyrics/new_timing.json` 与 `lyrics/PE_Annual_Party_新音轨.m4a`。

- **第二步：盘点分段素材完整性与时长**
  ```bash
  node tools/inventory_ancient.cjs
  ```

- **第三步：执行高精度裁切、拼接并合成完整带音轨 MV**
  ```bash
  node tools/check_and_stitch.cjs
  ```
  > 首次运行会逐段裁切生成 `_temp_trimmed/trim_01.mp4 ~ trim_16.mp4`；再次运行时若检测到已有裁切缓存会自动跳过重编码，数秒内完成拼接与音频混流，成品导出至 `delivery_古代篇_20261122/03_完整成品/`。

- **（可选）启动 Remotion 字幕/动效工程**
  ```bash
  cd film/motion-v2
  npm install
  ```
